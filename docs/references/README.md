# Chip reference library

PDFs are grouped by chip or family. [manifest.json](manifest.json) pins download bytes and provenance; [catalog.json](catalog.json) maps datasheet, functional reference and programming-guide roles to current models. The library contains 34 PDFs for 19 chip/family folders. A document does not imply whole-chip simulation.

Logic chips and GPIO expanders have no CPU: their datasheet is also the pin/register programming reference. The programming workflow and debugger are described in [PROGRAMMING.md](../PROGRAMMING.md).

Every revision is pinned explicitly. The S32K1xx reference manual is Rev. 13 from NXP Community, while NXP lists the newer Rev. 14.2 as account-required. A newer catalog listing does not silently change model behavior or citations. ETPURM is skipped at the user’s request; newly retrieved references provide context until their relevant behavior is implemented and verified.
