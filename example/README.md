# Chip examples

[Power controller](power-controller/README.md) is an original Tiny Tapeout IHP digital chip built through ChipSim MCP. It includes PWM/startup/fault RTL, independent public-pin tests, a portable MCP reproduction helper, and locally validated manufacturer handoff files.

This singular `example/` directory contains the requested manufacturing example. Existing model and tooling fixtures remain under `examples/`.
